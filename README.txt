ASPIRO — исходники сайта

Распакуйте архив и откройте index.html в браузере на компьютере.
Для работы сайта нужны только файлы из этой папки. Интернет,
установка пакетов и сборка для локального просмотра не требуются.

Что редактировать
  index.html          Текст, разделы, навигация и разметка демо
  styles.css          Оформление и адаптация под размер экрана
  demo.js             Синтетические данные, расчёт показателей и анимация
  aspiro-device.webp  Изображение концепта спирометра
  mark.svg            Иконка вкладки браузера

После правок сохраните файлы и обновите страницу. В демо проверьте
оба сценария, воспроизведение и сброс. Демо использует синтетические
данные и не подключается к реальному устройству.

Для публикации своей версии загрузите все пять файлов сайта на
статический хостинг. Файл index.html должен лежать в корне сайта
рядом с остальными файлами.
